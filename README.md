# Sentiment_Analysis
# Sentiment Analysis Dashboard

## Objective
Analyze customer reviews and classify them into Positive, Negative, and Neutral sentiments.

## Tools Used
- Power BI
- Power Query
- DAX

## KPIs
- Total Reviews
- Positive Reviews
- Negative Reviews
- Neutral Reviews

## Visualizations
- Cards
- Pie Chart
- Bar Chart
- Review Table

## Outcome
Identified customer sentiment trends and overall satisfaction levels.
